# Initial issue draft: establish the public infrastructure demonstration

Status: retained planning draft for the initial release; no hosted issue or PR is claimed.

## Problem

A reviewable engineering portfolio needs a runnable synthetic example with clear boundaries between data, Strategy, research, portfolio planning and execution.

## Acceptance criteria

- Provide artificial data with reproducible provenance.
- Demonstrate chronological backtesting, walk-forward analysis, bootstrap and parameter plateau analysis.
- Test risk sizing and broker preview mapping without network access.
- Provide ADRs, agent rules, issue/PR templates and CI.
- Include no private source files, history, datasets, operational settings or performance.

## Implementation branch

The initial implementation was prepared on `feat/portfolio-foundation` and reviewed locally. The owner approved the audit, license and initial publication on `main`. Subsequent changes should use a hosted issue and pull request with passing CI and human review. This draft does not claim a completed hosted issue or PR workflow for the initial import.
